## Things worth knowing for the interview, found while checking

- Boot 4.0 split the test support into modules (`spring-boot-<technology>-test`) and `@SpringBootTest` no longer provides MockMvc,
  `WebClient` or `TestRestTemplate` beans automatically (`@AutoConfigureMockMvc`, `RestTestClient`). The course questions do not depend
  on this; they avoid package names.
- Jackson 3 is Boot 4's default; `@JsonComponent` is now `@JacksonComponent` and defining a bare `ObjectMapper` bean is no longer enough
  (define a `JsonMapper`). Only the `@JsonTest` explanation mentions this.
