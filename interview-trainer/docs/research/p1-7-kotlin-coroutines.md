# P1-7: version-sensitive claims in the Kotlin and Coroutines units

Date of check: 2026-11-07. Files: `content/01-kotlin.yaml`, `content/02-coroutines.yaml`.

**Versions current on that date, as shown by the sources**

- Kotlin: latest stable 2.4.21 (Maven Central `kotlin-stdlib`, published 2026-10-08; 2.4.0 was published 2026-06-03). 2.5.0-Beta2 exists and is a pre-release.
- kotlinx.coroutines: 1.11.0 (Maven Central metadata `release` = 1.11.0, `kotlinx-coroutines-core` POM dated 2026-05-07). The source of tag 1.11.0 was read directly.

**Method.** Official documentation (kotlinlang.org, the KEEP, the kotlinx.coroutines and stdlib source with its KDoc) was read for every claim. Where a claim is about compiler or runtime behaviour, it was also compiled or run with the Kotlin 2.4.21 compiler against kotlinx.coroutines 1.11.0 (and `kotlinx-coroutines-test` 1.11.0), which settles what the *current* toolchain does. Those runs are marked "run" below. A language-version claim ("since 1.x") rests on the documentation, because the old compilers were not run.

Verdicts: **confirmed** (no change needed), **fixed** (a wrong or imprecise statement corrected), **softened** (version or qualifier added, or a detail trimmed), **key changed** (answer key altered; none were needed), **could not verify**.

Source shorthand: KDoc/src = `https://raw.githubusercontent.com/Kotlin/kotlinx.coroutines/1.11.0/kotlinx-coroutines-core/` followed by the path shown; Maven = `https://repo1.maven.org/maven2/org/jetbrains/`.

## Not verified

- Whether `suspend fun ...: Result<T>` was already legal at exactly Kotlin 1.5.0: the KEEP lifts the restriction for function return types in 1.5 without discussing suspend functions, and public discussion mentions suspend-specific `Result` bugs in 1.4/1.5 builds. Only the current compiler (2.4.21) was run. The course says only what is verified (allowed since 1.5 for functions, compiles on current compilers) and the answer key does not depend on the version.
- Language-version history (lateinit 1.2, sealed interfaces 1.5, `value` classes 1.5, `when` 1.6/1.7) comes from the official release notes and compatibility guides; older compilers were not run.
